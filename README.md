# Sistema Bancário em Java
Projeto desenvolvido em Java com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO).

## Funcionalidades
- Exibição dos dados da conta
- Consulta de saldo
- Depósito
- Pagamento em dinheiro
- Pagamento via PIX
- Pagamento com cartão
- Parcelamento de compras
- Validação de saldo e valores

## Conceitos utilizados
- Classes e objetos
- Encapsulamento
- Herança
- Interfaces
- Sobrecarga de métodos
- Construtores
- Estruturas condicionais
- Scanner
- Validações
## Estrutura do projeto
- Agencia.java — representa a agência bancária.
- Conta.java — classe base da conta.
- ContaCorrente.java — representa a conta corrente e os métodos de pagamento.
- Pagamento.java — interface responsável pelo método de pagamento.
- Principal.java — contém o menu e a execução do sistema.
## Tecnologias
- Java
- Programação Orientada a Objetos
## Objetivo
Este projeto foi desenvolvido como prática dos fundamentos de Java e POO, buscando fortalecer minha base para desenvolvimento backend.
